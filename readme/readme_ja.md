## 📋 プロジェクト概要

**Flickr 動画情報ツール** は、Flickr プラットフォーム上で**公開設定されている**動画・写真コンテンツのメタデータを分析・参照するための軽量ウェブアプリケーションです。学術研究、デジタルアーカイブ参考、メディア分析などの正当な用途において、コンテンツの技術的情報（タイトル、説明、撮影日時、ライセンス情報、解像度、アップロード者情報など）を可視化する支援を目的としており、プラットフォームのインフラやセキュリティ機構への干渉は一切行いません。

### ✨ 主な機能

- 🔍 **URL 解析**: 公開されている Flickr 動画/写真リンクを入力し、関連メタデータを照会
- 📊 **情報表示**: タイトル、説明、撮影日・アップロード日、ライセンス種別、解像度、タグ、アップロード者情報などを明確に表示
- 🌐 **日本語ローカライズ**: 完全な日本語インターフェース対応（日本国内および海外在住の日本語ユーザー向け）
- 📱 **レスポンシブデザイン**: デスクトップ、タブレット、スマートフォンなど、あらゆるデバイスで最適化された表示
- ⚡ **高速処理**: クライアントサイドでの検証と最適化された API 通信により、迅速なレスポンスを実現
- 🔒 **プライバシー重視**: ユーザーデータ、クエリ履歴、メディアコンテンツの一切を保存・記録しません

## 📖 利用ガイド

1. Flickr 上で**公開設定されている**動画または写真のリンクをコピーします
2. ツールの入力フィールドに URL を貼り付けます
3. 「分析」ボタンをクリックし、利用可能なメタデータの取得を待ちます
4. 表示された情報を、個人学習・研究ノート・合法的なデジタルコンテンツ管理の参考としてご活用ください

> ⚠️ 本ツールは公開権限を持つコンテンツのみを対象としています。プライバシー設定により保護されているコンテンツ、ログインが必要なコンテンツ、友人限定・家族限定のコンテンツは、技術的制限およびコンプライアンス要件により処理できません。

## ❓ よくある質問

**Q: 本ツールの利用に費用はかかりますか？**  
A: 完全無料です。本プロジェクトは MIT オープンソースライセンスで提供されており、合法的かつコンプライアンスを遵守した学習・利用を歓迎します。

**Q: 写真・動画ファイルはサーバーに一時的にキャッシュされますか？**  
A: いいえ。処理プロセスは純粋なメタデータ情報照会であり、メディアファイルの転送や一時保存は一切行われません。

**Q: 非公開設定の写真や動画も解析できますか？**  
A: 対応しておりません。技術的実現可能性および法的コンプライアンスの観点から、完全公開コンテンツのみを対象としています。

**Q: Creative Commons ライセンス情報は表示されますか？**  
A: はい。公開コンテンツに設定されたライセンス情報（CC BY、CC BY-SA 等）は可能な限り表示され、権利者帰属の参考としてご利用いただけます。

**Q: Flickr API キーは必要ですか？**  
A: 基本的なメタデータ照会は公開ページからの情報取得により処理されます。高度な機能利用時にはオプションで API キーの設定が可能ですが、必須ではありません。
