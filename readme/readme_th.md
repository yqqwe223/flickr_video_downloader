# Flickr Video Downloader - คำอธิบายโปรเจกต์

> เครื่องมือเบาๆ สำหรับดึงวิดีโอจาก Flickr ที่เปิดเป็นสาธารณะ มาบันทึกไว้ดูออฟไลน์ได้ พัฒนาขึ้นเพื่อใช้ส่วนตัวและศึกษาเทคนิคการใช้งาน กรุณาปฏิบัติตามข้อกำหนดการใช้งานและกฎหมายที่เกี่ยวข้องอย่างเคร่งครัด

🔗 ทดลองใช้งาน: [https://twittervideodownloaderx.com/flickr_downloader_th](https://twittervideodownloaderx.com/flickr_downloader_th)

## 📌 ที่มาของโปรเจกต์

เวลาเล่น Flickr หาภาพสวยๆ หรือวิดีโอเจ๋งๆ บ่อยครั้งที่เราเจอคลิปเด็ดๆ อย่างทามแลปส์พระอาทิตย์ตก, เบื้องหลังการถ่ายแบบ, หรือวิดีโอสั้นๆ จากทริปเดินทางที่เล่าเรื่องได้ลึกซึ้งกว่าภาพเดียว แต่ปัญหาคือแพลตฟอร์มไม่มีปุ่มให้ดาวน์โหลด เก็บลิงก์ไว้ก็ลืม อัดหน้าจอเองก็เสียเวลาแถมคุณภาพลด

เลยคิดว่า "ถ้าอย่างนั้นลองทำเครื่องมือง่ายๆ ไว้ใช้เองดีกว่า" จึงเกิดเป็นโปรเจกต์นี้ขึ้นมา โดยเน้นความเรียบง่าย ไม่ซับซ้อน ติดตั้งไม่ยาก และใช้งานได้จริง ใครที่มีความต้องการคล้ายกันก็นำโค้ดไปปรับใช้หรือศึกษาต่อได้เลย

## ✨ ฟีเจอร์หลัก

- ✅ ดึงลิงก์วิดีโอจากหน้าสาธารณะของ Flickr ได้ (รองรับอัลบั้มฝัง, หน้าโปรไฟล์, ลิงก์แชร์)
- ✅ ตรวจจับความละเอียดหลายระดับ และส่งกลับค่าคุณภาพต้นฉบับโดยอัตโนมัติ
- ✅ ระบบประมวลผลอยู่ฝั่งเซิร์ฟเวอร์ หน้าเว็บเบา โหลดเร็ว ไม่มีสคริปต์ติดตามพฤติกรรม
- ✅ รองรับ CORS ตั้งค่าให้เชื่อมต่อกับฟรอนต์เอนด์โปรเจกต์อื่นได้ง่าย
- ✅ บันทึกโลกรายการคำขอและสถานะการประมวลผล ช่วยตรวจสอบปัญหาได้เร็ว
- ✅ มีกลไกควบคุมความถี่ในการร้องขอเบื้องต้น ลดความเสี่ยงถูกบล็อก

## 🛠️ เทคโนโลยีที่ใช้

- ภาษา: Python 3.9 ขึ้นไป
- เฟรมเวิร์ก: Django 4.x
- HTTP Client: requests (หลัก), httpx (สำรองสำหรับโหมดอะซิงโครนัส)
- การแยกวิเคราะห์: Regular Expression + BeautifulSoup (ตามความจำเป็น)
- การปรับใช้: แนะนำ Gunicorn + Nginx, รองรับ Docker สำหรับติดตั้งเร็ว
- การจัดการคอนฟิก: ใช้ Environment Variables ร่วมกับ settings.py แบ่งตามสภาพแวดล้อม

ไลบรารีภายนอกที่ใช้มีน้อยที่สุด เพื่อลดปัญหาความเข้ากันได้และทำให้การติดตั้งราบรื่น

## 🚀 วิธีติดตั้งและเริ่มใช้งาน

### วิธีที่ 1: ติดตั้งจากซอร์สโค้ด

```bash
# 1. โคลนรีพอซิทอรี
git clone https://github.com/yourname/flickr-downloader.git
cd flickr-downloader

# 2. สร้าง virtual environment และติดตั้ง dependencies
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. คัดลอกและแก้ไขไฟล์คอนฟิก
cp .env.example .env
# แก้ไข .env กำหนด SECRET_KEY, ALLOWED_HOSTS และค่าอื่นๆ ตามต้องการ

# 4. รัน migration (หากต้องการใช้ฟีเจอร์บันทึกโลก)
python manage.py migrate

# 5. เริ่มเซิร์ฟเวอร์ (โหมดพัฒนา)
python manage.py runserver 0.0.0.0:8000

# โหมดผลิตแนะนำใช้ Gunicorn:
gunicorn core.wsgi:application --bind 0.0.0.0:8000 --workers 3
```

### วิธีที่ 2: ใช้ Docker

```bash
# สร้างอิมเมจ
docker build -t flickr-dl:latest .

# รันคอนเทนเนอร์
docker run -d -p 8000:8000 --env-file .env flickr-dl:latest
```

> 💡 คำแนะนำ: สำหรับการใช้งานจริง ควรตั้งค่า Nginx เป็น Reverse Proxy และเปิดใช้ HTTPS เพื่อความปลอดภัยในการส่งข้อมูล

## 📋 ตัวอย่างการใช้งาน

```bash
# ส่งคำขอผ่าน API (ใช้ curl)
curl -X POST https://your-domain.com/api/parse \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.flickr.com/photos/xxx/video/12345678"}'

# ผลลัพธ์ที่ได้
{
  "code": 200,
  "data": {
    "title": "ทามแลปส์พระอาทิตย์ขึ้นที่ดอยอินทนนท์",
    "author": "สมชาย ช่างภาพ",
    "video_url": "https://cdn.flickr.com/video/xxx.mp4",
    "thumbnail": "https://cdn.flickr.com/thumb/xxx.jpg",
    "duration": "03:45"
  }
}
```

หน้าเว็บมีฟอร์มง่ายๆ ให้วางลิงก์ → กดปุ่ม "วิเคราะห์" → ได้ลิงก์ดาวน์โหลดมาคลิกขวาบันทึกได้เลย สามขั้นตอนจบ

## ⚠️ ข้อควรระวังและข้อกำหนดการใช้งาน

1. เครื่องมือนี้รองรับเฉพาะวิดีโอที่**ตั้งค่าเป็นสาธารณะ**เท่านั้น เนื้อหาที่ต้องล็อกอินหรือเป็นส่วนตัวไม่สามารถดึงได้;
2. ห้ามนำไปใช้ดึงข้อมูลจำนวนมาก โอนย้ายเชิงพาณิชย์ หรือกระทำใดๆ ที่ขัดต่อข้อกำหนดการใช้งานของ Flickr;
3. ลิขสิทธิ์ของวิดีโอเป็นของผู้สร้างเนื้อหาหรือแพลตฟอร์ม กรุณาใช้เพื่อการศึกษา วิจัย หรืออ้างอิงอย่างเหมาะสมเท่านั้น;
4. การส่งคำขอถี่เกินไปอาจถูกจำกัดการเข้าถึง กรุณาใช้ฟังก์ชันควบคุมความถี่ที่มีอยู่ในโค้ด;
5. โปรเจกต์นี้ไม่จัดเก็บไฟล์วิดีโอใดๆ ทั้งสิ้น ลิงก์ที่ส่งกลับเป็นตรงจาก CDN ของ Flickr ซึ่งอาจมีอายุจำกัดตามนโยบายของแพลตฟอร์ม;
6. ผู้พัฒนาขอไม่รับผิดชอบต่อความเสียหายหรือปัญหาทางกฎหมายใดๆ ที่อาจเกิดขึ้นจากการใช้งานเครื่องมือนี้ กรุณาใช้ด้วยความระมัดระวังและรับผิดชอบต่อการกระทำของตนเอง

## 🔧 เคล็ดลับแก้ปัญหาเบื้องต้น

- **วิเคราะห์ล้มเหลวทันที**: Flickr อาจอัปเดตโครงสร้าง HTML ลองเช็ค Issues ล่าสุดหรือดึงโค้ดเวอร์ชันใหม่มาทดสอบ
- **ขึ้นข้อผิดพลาด 403/429**: คุณส่งคำขอถี่เกินไป เปิดใช้งาน delay ในคอนฟิกหรือลดจำนวนคำขอพร้อมกัน
- **ลิงก์วิดีโอหมดอายุเร็ว**: เป็นเรื่องปกติ — ลิงก์ CDN ของ Flickr มีอายุสั้น ดาวน์โหลดทันทีหลังวิเคราะห์เสร็จ
- **Docker ไม่เริ่มทำงาน**: ตรวจสอบไวยากรณ์ไฟล์ .env และแน่ใจว่าพอร์ต 8000 ว่างไม่ได้ถูกใช้งาน
