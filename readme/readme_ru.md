# Flickr Video Downloader - Документация проекта

> Лёгкий инструмент для извлечения и сохранения публичных видео с Flickr. Разработан для личного использования и технического изучения. Пожалуйста, соблюдайте условия использования платформы и действующее законодательство.

🔗 Онлайн-демо: [https://twittervideodownloaderx.com/flickr_downloader_ru](https://twittervideodownloaderx.com/flickr_downloader_ru)

---

## 📌 Зачем я это написал?

Будем честны: когда бродишь по Flickr в поисках визуального вдохновения, иногда натыкаешься на действительно крутые видео. Таймлапсы закатов, бэкстейджи фотосессий, короткие тревел-влоги, которые рассказывают больше, чем одна фотография... Но вот засада — кнопки «скачать» нет и в помине. Сохранишь ссылку в закладки — и забудешь на месяц. Записать экран? Качество просядет, времени уйдёт куча, да и файл на выходе весит прилично.

Вот и подумал: «А не сделать ли мне простую штуку, которая просто работает?». Так и появился этот проект. Без наворотов, без перегруженного интерфейса — только суть: вставил ссылку → получил видео. Код чистый, зависимости сведены к минимуму, установка не должна вызвать головной боли. Если пригодится и вам — отлично. Если захотите заглянуть внутрь или предложить улучшения — ещё лучше.

## ✨ Что умеет

- ✅ Извлекает публичные видео с Flickr (поддерживает встроенные альбомы, страницы профиля, шаринговые ссылки)
- ✅ Автоматически определяет доступные качества и приоритизирует оригинал при наличии
- ✅ Вся тяжёлая логика на бэкенде; фронтенд — минималистичная форма → быстрая загрузка, никаких трекеров
- ✅ CORS уже настроен для лёгкой интеграции с другими фронтенд-проектами
- ✅ Базовое логирование запросов и статуса парсинга для удобного дебага
- ✅ Встроенное ограничение частоты запросов для снижения риска блокировки со стороны Flickr

---

## 🛠️ Технологический стек

- Язык: Python 3.9+
- Фреймворк: Django 4.x (лёгкий, гибкий, идеален для таких задач)
- HTTP-клиент: requests (основной), httpx (опционально для асинхронного режима)
- Парсинг: регулярные выражения + BeautifulSoup (только когда действительно нужно)
- Деплой: рекомендуется Gunicorn + Nginx; есть поддержка Docker для быстрого старта
- Конфигурация: переменные окружения + settings.py с разделением по окружениям (dev/prod)

Внешние зависимости намеренно сведены к минимуму, чтобы избежать конфликтов версий и упростить установку.

## 🚀 Быстрый старт

### Вариант 1: Из исходного кода

```bash
# 1. Клонируем репозиторий
git clone https://github.com/yourname/flickr-downloader.git
cd flickr-downloader

# 2. Создаём venv и ставим зависимости
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. Копируем и настраиваем конфиг
cp .env.example .env
# Правим .env: указываем SECRET_KEY, ALLOWED_HOSTS и прочее

# 4. Применяем миграции (если нужно логирование в БД)
python manage.py migrate

# 5. Запускаем сервер разработки
python manage.py runserver 0.0.0.0:8000

# Для продакшена лучше использовать Gunicorn:
gunicorn core.wsgi:application --bind 0.0.0.0:8000 --workers 3
```

### Вариант 2: Docker (для тех, кто не любит возиться)

```bash
# Собираем образ
docker build -t flickr-dl:latest .

# Запускаем контейнер
docker run -d -p 8000:8000 --env-file .env flickr-dl:latest
```

> 💡 Совет на будущее: в продакшене обязательно настройте Nginx как reverse proxy и включите HTTPS. Безопасность — это не опция.

## ⚠️ Важно прочитать перед использованием

1. Инструмент работает только с **публичными** видео на Flickr. Контент, требующий входа или помеченный как приватный, обрабатываться не будет;
2. Категорически запрещено использовать скрипт для массового скрейпинга, коммерческого распространения или любых действий, нарушающих Условия использования Flickr;
3. Права на видео принадлежат авторам или платформе. Скачанный контент используйте только для личного изучения, исследований или цитирования в разумных пределах;
4. Слишком частые запросы за короткое время могут активировать защитные механизмы. В коде есть базовая задержка между запросами — включите её, чтобы избежать проблем;
5. Проект НЕ хранит видеофайлы. Возвращаемые ссылки ведут напрямую на официальный CDN Flickr и могут перестать работать в любой момент согласно политике платформы;
6. Разработчик не несёт юридической или технической ответственности за проблемы, возникшие в результате использования этого инструмента. Используете — на свой страх и риск.

## 🔧 Быстрое решение проблем

- **Парсинг внезапно перестал работать**: вероятно, Flickr обновил HTML. Проверьте открытые Issues или обновите код из репозитория.
- **Ошибки 403/429**: вы уперлись в лимит запросов. Включите задержку в настройках или уменьшите количество одновременных запросов.
- **Ссылка на видео быстро протухает**: это нормально — URL с CDN Flickr живут недолго. Скачивайте сразу после парсинга.
- **Docker не запускается**: проверьте синтаксис .env и убедитесь, что порт 8000 не занят.
