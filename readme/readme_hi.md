# Flickr Video Downloader - प्रोजेक्ट दस्तावेज़

> फ्लिकर से पब्लिक वीडियो निकालने और सेव करने का हल्का-फुल्का टूल। पर्सनल यूज़ और टेक्निकल स्टडी के लिए बनाया गया है। प्लीज़ प्लेटफॉर्म के टर्म्स और अपने देश के कानूनों का ध्यान रखें।

## 📌 ये प्रोजेक्ट क्यों बनाया?

सच बात बोलूं तो जब भी फ्लिकर पर कुछ ढूंढने या ब्राउज़ करने जाता हूं, कभी-कभी ऐसे वीडियो मिल जाते हैं जो सच में काम के होते हैं — लैंडस्केप टाइमलैप्स, फोटोशूट के बीहाइंड-द-सीन, शॉर्ट ट्रैवल व्लॉग जो एक सिंगल इमेज से ज्यादा कहानी बताते हैं। लेकिन प्रॉब्लम ये है कि डाउनलोड बटन ही नहीं होता। लिंक सेव करके भूल जाना तो आम बात है, और स्क्रीन रिकॉर्ड करना? क्वालिटी गिर जाती है, टाइम लगता है, और फाइनल फाइल भी भारी हो जाती है।

तो सोचा, "क्यों न खुद का एक सिंपल टूल बना लूं जो बस काम कर दे?" बस यहीं से ये प्रोजेक्ट शुरू हुआ। न कोई फालतू फीचर, न भारी-भरकम इंटरफेस — बस इतना: लिंक पेस्ट करो → वीडियो लिंक मिल जाए। कोड क्लीन रखा है, डिपेंडेंसीज़ कम से कम रखी हैं, और इंस्टॉलेशन भी हेडएक नहीं देगा। अगर आपको भी काम आए, तो बढ़िया। अगर कोड देखना या इम्प्रूव करना चाहें, तो और भी अच्छा।

## ✨ ये क्या कर सकता है

- ✅ फ्लिकर के पब्लिक वीडियो लिंक्स पार्स करता है (अल्बम एम्बेड, प्रोफाइल पेज, शेयर लिंक सब सपोर्टेड)
- ✅ ऑटोमैटिकली मल्टीपल रेजोल्यूशन डिटेक्ट करता है और ओरिजिनल क्वालिटी को प्रायोरिटी देता है
- ✅ सारा हेवी लिफ्टिंग बैकएंड पर, फ्रंटएंड बस एक सिंपल फॉर्म → फास्ट लोड, जीरो ट्रैकिंग स्क्रिप्ट
- ✅ CORS पहले से कॉन्फ़िगर है, दूसरे फ्रंटएंड प्रोजेक्ट्स के साथ इंटीग्रेट करना आसान
- ✅ बेसिक रिकवेस्ट लॉग + पार्स स्टेटस, डिबगिंग में मदद के लिए
- ✅ रेट लिमिटिंग बिल्ट-इन है, फ्लिकर की तरफ से ब्लॉक होने का रिस्क कम

## 🛠️ टेक स्टैक

- लैंग्वेज: Python 3.9+
- फ्रेमवर्क: Django 4.x (हल्का, एक्सटेंड करने में आसान)
- HTTP क्लाइंट: requests (मेन), httpx (ऑप्शनल, असिंक मोड के लिए)
- पार्सिंग: रेगेक्स + BeautifulSoup (जरूरत पड़ने पर)
- डिप्लॉय: Gunicorn + Nginx रिकमेंडेड; Docker सपोर्ट भी है क्विक सेटअप के लिए
- कॉन्फ़िग मैनेजमेंट: एनवायरनमेंट वेरिएबल्स + settings.py को डेव/प्रोड के हिसाब से अलग-अलग

बाहरी डिपेंडेंसीज़ को जानबूझकर कम रखा है ताकि वर्जन कॉन्फ्लिक्ट्स से बचा जा सके और इंस्टॉलेशन स्मूथ रहे।

## 🚀 क्विक स्टार्ट गाइड

### ऑप्शन 1: सोर्स कोड से रन करें

```bash
# 1. रेपो क्लोन करें
git clone https://github.com/yourname/flickr-downloader.git
cd flickr-downloader

# 2. वर्चुअल एनवायरनमेंट बनाएं और डिपेंडेंसीज़ इंस्टॉल करें
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. कॉन्फ़िग फाइल कॉपी और एडिट करें
cp .env.example .env
# .env एडिट करें: SECRET_KEY, ALLOWED_HOSTS वगैरह सेट करें

# 4. माइग्रेशन रन करें (अगर डीबी में लॉगिंग चाहिए)
python manage.py migrate

# 5. डेवलपमेंट सर्वर स्टार्ट करें
python manage.py runserver 0.0.0.0:8000

# प्रोडक्शन के लिए Gunicorn यूज़ करें:
gunicorn core.wsgi:application --bind 0.0.0.0:8000 --workers 3
```

### ऑप्शन 2: Docker (आलसियों के लिए)

```bash
# इमेज बिल्ड करें
docker build -t flickr-dl:latest .

# कंटेनर रन करें
docker run -d -p 8000:8000 --env-file .env flickr-dl:latest
```

> 💡 प्रो टिप: प्रोडक्शन में हमेशा Nginx को रिवर्स प्रॉक्सी की तरह सेट करें और HTTPS फोर्स करें। सिक्योरिटी ऑप्शनल नहीं है।

## 📋 API यूज़ेज उदाहरण

```bash
# curl से टेस्ट करें
curl -X POST https://your-domain.com/api/parse \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.flickr.com/photos/xxx/video/12345678"}'

# एक्सपेक्टेड JSON रेस्पॉन्स
{
  "code": 200,
  "data": {
    "title": "लद्दाख सनराइज टाइमलैप्स",
    "author": "राहुल फोटोग्राफर",
    "video_url": "https://cdn.flickr.com/video/xxx.mp4",
    "thumbnail": "https://cdn.flickr.com/thumb/xxx.jpg",
    "duration": "04:12"
  }
}
```

वेब इंटरफेस में बस एक बेसिक फॉर्म है: लिंक पेस्ट करो → "Parse" पे क्लिक करो → डाउनलोड बटन मिल जाएगा। तीन स्टेप, बस। कोई फालतू चीज़ नहीं।

## ⚠️ इस्तेमाल करने से पहले ये ज़रूर पढ़ें

1. ये टूल सिर्फ **पब्लिक** वीडियो के साथ काम करता है। लॉगिन वाला या प्राइवेट कंटेंट प्रोसेस नहीं होगा;
2. मास स्क्रैपिंग, कमर्शियल रीडिस्ट्रीब्यूशन, या फ्लिकर के टर्म्स ऑफ सर्विस के खिलाफ किसी भी एक्शन के लिए इसका इस्तेमाल बिल्कुल न करें;
3. वीडियो के राइट्स क्रिएटर या प्लेटफॉर्म के पास होते हैं। डाउनलोड किए गए कंटेंट का इस्तेमाल सिर्फ पर्सनल स्टडी, रिसर्च, या फेयर साइटेशन के लिए करें;
4. थोड़े समय में बहुत सारी रिकवेस्ट्स भेजने से रेट लिमिट ट्रिगर हो सकती है। कोड में बेसिक डिले मैकेनिज्म है — इसे एनेबल करें;
5. ये प्रोजेक्ट कोई वीडियो फाइल स्टोर नहीं करता। रिटर्न किए गए लिंक्स फ्लिकर के ऑफिशियल CDN से डायरेक्ट होते हैं और प्लेटफॉर्म की पॉलिसी के हिसाब से एक्सपायर हो सकते हैं;
6. इस टूल के इस्तेमाल से होने वाले किसी भी लीगल या टेक्निकल इश्यू की जिम्मेदारी डेवलपर नहीं लेता। इस्तेमाल अपनी रिस्क पर करें।

## 🔧 क्विक ट्रबलशूटिंग टिप्स

- **पार्सिंग अचानक फेल होने लगे**: फ्लिकर ने शायद अपना HTML अपडेट कर दिया है। रीसेंट Issues चेक करें या कोड अपडेट करें।
- **403/429 एरर्स आ रहे हैं**: आप रेट लिमिट क्रॉस कर रहे हैं। कॉन्फिग में डिले एनेबल करें या कन्करेंट रिकवेस्ट्स कम करें।
- **वीडियो URL जल्दी एक्सपायर हो रहा है**: ये नॉर्मल है — फ्लिकर CDN लिंक्स का TTL छोटा होता है। पार्स करने के तुरंत बाद डाउनलोड कर लें।
- **Docker स्टार्ट नहीं हो रहा**: .env फाइल की सिंटैक्स चेक करें और सुनिश्चित करें कि पोर्ट 8000 फ्री है।
