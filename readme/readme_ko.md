# Flickr 동영상 다운로더 - 프로젝트 안내

> 플리커 공개 동영상을 간편하게 추출하고 로컬에 저장할 수 있는 가벼운 도구입니다. 개인 학습 및 기술 연구 목적으로 제작되었으니, 플랫폼 이용약관 및 관련 법규는 꼭 지켜주세요.

🔗 실시간 데모: [https://twittervideodownloaderx.com/flickr_downloader_ko](https://twittervideodownloaderx.com/flickr_downloader_ko)

## 📌 왜 만들게 됐냐면

플리커 서핑하다가 좋은 작품 만날 때 있잖아요. 타임랩스 영상, 여행 브이로그, 포토그래퍼의 비하인드 클립 같은 거. 근데 막상 저장하려고 하면 다운로드 버튼은 없고, 북마크해놓고는 까먹고... 화면 녹화하자니 화질도 떨어지고 시간도 뺏기고.

"차라리 내가 직접 간단하게 만들어보자" 싶은 마음에 시작했습니다. 복잡한 기능 빼고, 핵심만 딱: 링크 붙여넣기 → 영상 링크 추출. 코드도 깔끔하게 정리했고, 의존성도 최소화해서 설치도 어렵지 않아요.

---

## ✨ 주요 기능

- ✅ 플리커 공개 동영상 링크 파싱 지원 (앨범 임베드, 프로필 페이지, 공유 링크 등)
- ✅ 여러 화질 자동 감지 후 오리지널 품질 우선 반환
- ✅ 백엔드에서 처리, 프론트는 심플하게 → 로딩 빠르고 트래킹 스크립트 없음
- ✅ CORS 설정 완료, 다른 프론트 프로젝트와 연동도 수월
- ✅ 요청 로그 및 파싱 상태 기록으로 디버깅 편의성 제공
- ✅ 기본 요청 간격 제어 기능으로 차단 위험 감소

## 🛠️ 사용 기술

- 언어: Python 3.9 이상
- 프레임워크: Django 4.x
- HTTP 클라이언트: requests (메인), httpx (비동기 옵션)
- 파싱: 정규식 + BeautifulSoup (필요시)
- 배포: Gunicorn + Nginx 권장, Docker 도 지원
- 설정: 환경변수 + settings.py 로 환경별 분리

외부 라이브러리는 꼭 필요한 것만 써서 버전 충돌이나 설치 오류를 줄였습니다.

## 🚀 빠른 설치 가이드

### 방식 1: 소스코드로 실행

```bash
# 1. 저장소 클론
git clone https://github.com/yourname/flickr-downloader.git
cd flickr-downloader

# 2. 가상환경 생성 및 의존성 설치
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. 설정 파일 복사 후 수정
cp .env.example .env
# .env 편집: SECRET_KEY, ALLOWED_HOSTS 등 필수 항목 입력

# 4. 데이터베이스 마이그레이션 (로그 기능 사용시)
python manage.py migrate

# 5. 개발 서버 실행
python manage.py runserver 0.0.0.0:8000

# 운영환경에서는 Gunicorn 권장:
gunicorn core.wsgi:application --bind 0.0.0.0:8000 --workers 3
```

### 방식 2: Docker 로 한방에

```bash
# 이미지 빌드
docker build -t flickr-dl:latest .

# 컨테이너 실행
docker run -d -p 8000:8000 --env-file .env flickr-dl:latest
```

> 💡 참고: 실제 서비스 운영시에는 Nginx 리버스 프록시 + HTTPS 설정을 꼭 해주세요. 보안은 선택이 아니라 필수입니다.

## 📋 사용 예시

```bash
# curl 로 API 테스트
curl -X POST https://your-domain.com/api/parse \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.flickr.com/photos/xxx/video/12345678"}'

# 응답 예시
{
  "code": 200,
  "data": {
    "title": "제주도 일출 타임랩스",
    "author": "김사진가",
    "video_url": "https://cdn.flickr.com/video/xxx.mp4",
    "thumbnail": "https://cdn.flickr.com/thumb/xxx.jpg",
    "duration": "03:45"
  }
}
```

웹 페이지에는 간단한 폼이 준비되어 있어요: 링크 붙여넣기 → "분석" 클릭 → 다운로드 버튼 등장. 세 단계면 끝납니다.

## 🔧 자주 묻는 문제 해결

- **파싱이 갑자기 안 될 때**: 플리커가 HTML 구조를 업데이트했을 확률이 높아요. 최근 Issue 를 확인하거나 코드를 최신으로 업데이트해 보세요.
- **403/429 에러가 나올 때**: 요청 제한에 걸린 거예요. 설정에서 딜레이를 활성화하거나 동시 요청 수를 줄여주세요.
- **비디오 링크가 빨리 만료될 때**: 정상입니다. 플리커 CDN 링크는 수명이 짧아요. 파싱 직후 빠르게 다운로드하세요.
- **Docker 가 안 켜질 때**: .env 파일 문법을 다시 확인하고, 8000 포트가 다른 프로세스에 점유되지 않았는지 체크하세요.
