## 📌 ليه فكرت في المشروع ده؟

أي حد بيدوّر على إلهام بصري في فليكر، أكيد صادف فيديوهات تخطف العين: تايملابس لغروب الشمس، كواليس جلسات تصوير، فلوجات سفر قصيرة تحكي قصة أحلى من صورة... لكن المشكلة؟ مفيش زر تحميل خالص. تحفظ الرابط في المفضلة وتنسى، أو تحاول تسجّل الشاشة وتفقد الجودة وتضيع الوقت.

فقلت لنفسي: "ليه ما أعملش أداة بسيطة تحل المشكلة دي؟". ومن هنا بدأ المشروع: من غير تعقيد، سهل التثبيت، وبيعمل اللي مفروض يعمله بالظبط. لو هتفيدك أنت كمان، تمام. ولو حبيت تلقي نظرة على الكود أو تطوّره، أحسن.

## ✨ الميزات الأساسية

- ✅ استخراج روابط الفيديو العامة من فليكر (بما في ذلك الألبومات المضمّنة، صفحات البروفايل، روابط المشاركة)
- ✅ كشف تلقائي لجودات متعددة واختيار الجودة الأصلية بشكل افتراضي
- ✅ المعالجة تتم في الخلفية (Backend)، والواجهة الأمامية خفيفة جداً: تحميل سريع ومن غير سكربتات تتبع
- ✅ إعدادات CORS جاهزة لتسهيل الدمج مع مشاريع الويب الأخرى
- ✅ تسجيل الطلبات وحالة التحليل في ملفات Log، عشان يسهل تتبع الأخطاء
- ✅ تحكم في معدل الطلبات لتجنب الحظر بسبب الضغط الزائد على الخادم

## 🛠️ الأدوات والتقنيات المستخدمة

- اللغة: بايثون 3.9 فأعلى
- الإطار: Django 4.x
- عميل HTTP: requests (أساسي)، httpx (اختياري للوضع غير المتزامن)
- تحليل المحتوى: تعابير منتظمة + BeautifulSoup (عند الحاجة)
- النشر: يُفضّل استخدام Gunicorn + Nginx؛ ومتوافق أيضاً مع Docker
- إدارة الإعدادات: متغيرات البيئة + ملف settings.py مفصل حسب البيئة (تطوير/إنتاج)

تم تقليل الاعتماد على المكتبات الخارجية لأدنى حد ممكن، عشان نقلل مشاكل التعارض ونسهل عملية التثبيت.

## 🚀 طريقة التثبيت السريع

### الطريقة الأولى: من الكود المصدري

```bash
# 1. استنساخ المستودع
git clone https://github.com/yourname/flickr-downloader.git
cd flickr-downloader

# 2. إنشاء بيئة افتراضية وتثبيت المتطلبات
python -m venv venv
source venv/bin/activate  # ويندوز: venv\Scripts\activate
pip install -r requirements.txt

# 3. نسخ وتعديل ملف الإعدادات
cp .env.example .env
# عدّل ملف .env: أضف SECRET_KEY، ALLOWED_HOSTS، وغيرها

# 4. تشغيل ترحيلات قاعدة البيانات (لو بتستخدم تسجيل في الداتابيز)
python manage.py migrate

# 5. تشغيل الخادم (وضع التطوير)
python manage.py runserver 0.0.0.0:8000

# للإنتاج، يُفضّل استخدام Gunicorn:
gunicorn core.wsgi:application --bind 0.0.0.0:8000 --workers 3
```

### الطريقة الثانية: باستخدام Docker

```bash
# بناء الصورة
docker build -t flickr-dl:latest .

# تشغيل الحاوية
docker run -d -p 8000:8000 --env-file .env flickr-dl:latest
```

> 💡 نصيحة مهمة: في بيئة الإنتاج، لازم تضبط Nginx كـ Reverse Proxy وتفعّل HTTPS. الأمان مش رفاهية.

## 📋 مثال على طريقة الاستخدام

```bash
# إرسال طلب للـ API باستخدام curl
curl -X POST https://your-domain.com/api/parse \
  -H "Content-Type: application/json" \
  -d '{"url": "https://www.flickr.com/photos/xxx/video/12345678"}'

# النتيجة المتوقعة
{
  "code": 200,
  "data": {
    "title": "تايملابس غروب في الصحراء",
    "author": "أحمد المصور",

  }

```

الواجهة الويب فيها نموذج بسيط: الصق الرابط → اضغط "تحليل" → يظهر لك زر التحميل. ثلاث خطوات وبس، من غير تعقيد.

## ⚠️ تنبيهات هامة وإخلاء مسؤولية

1. الأداة دي بتشتغل فقط مع الفيديوهات **العامة**. المحتوى الخاص أو اللي بيتطلب تسجيل دخول مش مدعوم؛
2. ممنوع استخدام الأداة لجمع البيانات بشكل آلي، أو إعادة التوزيع التجاري، أو أي فعل يخالف شروط استخدام فليكر؛
3. حقوق الفيديو تعود لصاحب المحتوى أو للمنصة. يُرجى الاستخدام لأغراض الدراسة، البحث، أو الاقتباس المعقول فقط؛
4. إرسال عدد كبير من الطلبات في وقت قصير قد يفعّل أنظمة الحماية من الإساءة. يُفضّل ضبط الفواصل الزمنية بين الطلبات من خلال الإعدادات؛
5. المشروع مش بيخزّن أي ملفات فيديو. الروابط اللي بتترجع هي روابط مباشرة من شبكة توصيل المحتوى الرسمية (CDN) الخاصة بفليكر، وقد تنتهي صلاحيتها حسب سياسات المنصة؛
6. المطوّر غير مسؤول عن أي مشاكل قانونية أو فنية تنتج عن استخدام هذه الأداة. الاستخدام على مسؤوليتك الشخصية.

## 🔧 حلول سريعة للمشاكل الشائعة

- **التحليل فشل فجأة**: غالباً فليكر حدّث هيكل الصفحة. شوف الـ Issues الأخيرة أو حدّث الكود من المستودع.
- **أخطاء 403/429**: وصلت لحد الطلبات المسموح. فعّل التأخير بين الطلبات في الإعدادات أو قلل عدد الطلبات المتزامنة.
- **رابط الفيديو بيبطل سريعاً**: ده طبيعي — روابط الـ CDN بتاعت فليكر عمرها قصير. نزّل الفيديو بسرعة بعد ما تحصل على الرابط.
- **Docker ما بيشتغلش**: تأكد من صيغة ملف .env وتأكد إن البورت 8000 فاضي ومش مستخدم.
